# Simple Line Editor in C

Team Members - Sarvesh Kamlesh Murthy.

## Compilation & Run Instructions
To compile the system cleanly using gcc, run:
```bash
gcc -Wall -Wextra -std=c99 main.c -o editor
```
To run the editor:
```bash
./lineeditor
```

## Features Implemented
* Core: Display document, Insert line, Delete line, Save/Load file.
* Bonus: Document word and line tracking metrics.
